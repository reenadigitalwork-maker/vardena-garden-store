# Vardena — Gardening for Small Spaces

A responsive static e-commerce **portfolio concept** for a modern gardening brand focused on balconies, windowsills and compact homes.

## Included
- Responsive homepage built with semantic HTML, CSS and vanilla JavaScript
- Product category filters and live text search
- Demo bag interaction; no checkout or payments
- Newsletter demo that does not send or store email addresses
- SEO basics: title, meta description, Open Graph metadata, semantic headings and descriptive image alt text
- Keyboard focus and reduced-motion support
- No framework, build step, API key or paid service required

## Run
Open `index.html` in a browser. Remote photos and web fonts need an internet connection.

## Free deployment with Cloudflare Pages
1. Sign in at Cloudflare and open Workers & Pages.
2. Choose Create application → Pages → Connect to Git.
3. Select `reenadigitalwork-maker/vardena-garden-store`.
4. Choose the `main` branch.
5. Leave the build command empty and set build output directory to `/` (repository root).
6. Deploy and save the exact `*.pages.dev` address.

Once the final public address is known, add the correct canonical URL, robots.txt and sitemap. Never guess the URL in SEO files.

## Portfolio honesty
This is a concept/demo, not a live retailer. Product names and prices are illustrative. The demo bag does not place orders, and the newsletter form does not collect or transmit personal information. Real sales need verified products, accurate pricing, shipping/returns information, customer support and secure checkout.

## SEO follow-up
- Confirm the deployed hostname before adding canonical tags and sitemap URLs.
- Test mobile layout, keyboard navigation, alt text and performance.
- Replace or appropriately license imagery before commercial use.
- Publish useful, original growing guides based on reliable horticultural sources.
- Set up Google Search Console once the site is publicly reachable and submit a valid sitemap.
- Indexing and rankings are not guaranteed.
